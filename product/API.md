# 标准产品与样例标签 API 契约 v1

标准产品 `0.2.0-w1`，作业契约 `w01-0.2.0`。以下接口及数据语义向两条实现路线开放。内部类名、LangGraph 节点和数据库表不是跨技术栈验收要求。

## 数据

`sample_data/` 为独立虚构的松果生活样例。业务参考日期固定为 2026-09-01；两个完整月份为 7 月和 8 月。时间区间左闭右开；金额以人民币分存储，已支付金额减去退款，取消订单不计。老会员为基期开始前入会的会员；基期大于零且下降至少 20% 的会员进入下降人群。零基期下降比例未定义，不当成 0% 或 100%。

CSV 的会员、订单、门店关系及覆盖区间必须验证。S01/S02 覆盖两个月，S03 只覆盖 7 月。S03 的 8 月未知，不能推断没有消费。干净样例有 9 位会员、14 条订单、3 家门店；默认比较的下降人群是 M001、M004、M007。M001 净消费 100000 分到 40000 分；M004 为 40000 分到 0，M007 为 10000 分到 0。M002 持平、M003 增长、M005 零基期、M006 非老会员、M008/M009 在未覆盖门店。

默认产品重复导入同一包不产生重复行。青禾原始数据需由学员按周清洗、映射和导入另一实例；不把样例 SQL 结果冒充青禾指标。

## 独立标签系统

默认本机 `http://127.0.0.1:8766`。所有请求带 `Authorization: Bearer training-demo-token`。这是公开教学凭据，仅用于本机样例；`training-demo-token-reader` 只有读取权限。可以通过 `FDE_MOCK_TOKEN` 覆盖，两端配置必须一致。错误不回显凭据。

| 方法与路径 | 请求体 | 成功行为 |
|---|---|---|
| GET /health | 无 | 返回服务与版本 |
| PUT /v1/tag-actions/{id} | `{ "member_id": "M001", "tag": "recall_review" }` | 幂等添加标签，保存动作与实际标签状态 |
| GET /v1/tag-actions/{id} | 无 | 查询动作状态、参数、当前标签状态和版本 |
| POST /v1/tag-actions/{id}/undo | `{}` | 撤销该动作，恢复它执行前的标签状态；重复撤销不重复生效 |

动作 ID 为 1–80 个字母、数字或连字符，客户端生成并持久保存。标签只允许 `recall_review` 与 `follow_up`，会员只允许 M001–M009。未知或多余字段为 400；缺少或错误凭据 401；只读凭据写操作 403；未知路径/动作 404；同键不同参数或后续状态冲突 409。

成功响应包含 `action_id`、`status`（applied/undone）、`payload`、`label_active`、`label_version`。同一 ID 和相同参数重复请求返回已有动作，不再次添加；同一 ID 不同参数拒绝。撤销前如果标签已被其他动作改变，返回 409，避免覆盖后续有效操作。已经存在的标签在重复添加后撤销应恢复为存在。

服务端存储与分析 SQLite 分开，进程重启后仍可查询。网络结果未知时，先 GET 查询，不能把超时当成未执行；404 也不能证明仍在途的写请求不会生效。官方账本保持 unknown，交由核对。W8 的客户 API 会另发契约与业务规则。

## 产品交互入口

默认 `http://127.0.0.1:8765`，仅本机单人使用。GET `/` 打开页面。POST 需 JSON 和 `X-FDE-Client: local-ui`；浏览器 Origin 必须与本机 Host 一致。

| 路径 | 输入 | 输出与约束 |
|---|---|---|
| /api/run | `text`、可选 `session_id`、`action_mode` | 返回运行状态、结构化结果、工具依据和 trace_id；主机未启用动作时，请求不能打开写权限 |
| /api/select-time | `session_id`、`option_id`、`options_token`、可选 `action_mode` | 只能确认当前任务最新显示的日期方案；旧方案、其他任务的方案或重复确认会拒绝 |
| /api/resume | `session_id`、`draft_hash`、布尔值 `approved` | 只恢复已有待确认草案；主机角色、会话、内容哈希均需匹配 |
| /api/undo | `session_id`、`action_id` | 对本会话已执行且支持撤销的样例动作执行显式撤销 |

会话 ID 限 1–80 位字母、数字、下划线或连字符。运行状态包括 completed、clarification、refused、incomplete、awaiting_approval、rejected。completed 表示本轮任务完成，不是模型每个自然语言判断均已自动证明。结果中金额和人群仍要回到工具依据。缺少必要时间条件先澄清；全部数据未覆盖时应 incomplete 并说明未知，不生成虚假召回名单。

确认是独立的人类请求，绑定草案 ID、会话及内容哈希。更换目标或参数需要拒绝旧草案并新建。拒绝后直接返回 rejected，不再调用模型、不写标签；同一任务可以接受新要求。未执行草案的查询读取本地账本，不请求标签 API。拒绝只说明本次未执行，不代表该会员原先没有此标签。模型文字和工具内容不能授予权限。动作由 LangGraph 持久化中断与独立账本共同执行，不能只靠 checkpoint 宣称副作用 exactly-once。

## 自主实现与验收

自主实现可以使用其他语言和数据库，并通过适配入口输出相同的结果与证据。`tools/probe_custom_contract.mjs` 是独立 Node 最小互操作验证：读取同一 CSV、自行计算、自行组织模型工具调用，并调用标签 API。它不是完整自建作业，尚不能代替全部澄清、持久确认、评估和安全要求。

正式 W1 提交四份 JSON 与立项报告，见契约目录。checker 验证文件与证据哈希；助教还要重跑真实模型行为、检查 HTTP 状态并抽查源码。自己写出的 JSON、固定回放及按钮直连 API 都不能替代 Agent 任务验证。

## 时间条件的程序校验

比较工具执行前，程序把请求时段与用户明确给出的时段核对。W1 入口支持两个带年份的自然月（如“2026 年 8 月相较 7 月”），或四个 ISO 边界日期并明确说明结束日期不包含当天。相对时间、无年份月份和存在歧义的日期先澄清；固定业务参考日期不能自动变成用户授权的范围。模型擅自调用会得到 `TIME_RANGE_NOT_CONFIRMED`，不读取分析数据。范围在会话中持久化；新消息改变时间条件时重新核对。


clarification 可返回 `time_options`（每项含 `id`、`label`、`windows`）与 `time_options_token`。日期由模型提出，程序校验并生成按钮，用户确认前不会自动查询。可在同一任务回复“就按你说的第一个方案，下降至少 20%”；程序只接受对本轮选项的明确选择，否定、询问或修改日期的表达仍需澄清。方案、确认范围和草案均持久保存，重启后继续核对。日期确认不授予标签执行权限。

接口错误保留 `error` 机器编号，同时返回中文 `message`。`CONFIRM_OR_CANCEL_PENDING_DRAFT` 提示先处理当前草案，`NO_PENDING_DRAFT` 表示草案已处理，`TIME_OPTION_EXPIRED` 表示需使用当前日期方案或重新输入完整月份。

## 订单笔数与退款说明

`baseline_orders`、`current_orders` 表示已支付订单笔数，其中包含全额退款单。比较结果新增 `order_breakdown.baseline/current`：支付笔数、其中全额退款笔数、取消笔数、支付／退款／净消费分值，以及支付和取消订单 ID。M001 的 8 月有 2 笔已支付订单，其中 1 笔全额退款；支付 500 元减去退款 100 元，净消费为 400 元，另有 1 笔取消订单未计入。全额退款单不能再加到那 2 笔之外。

完成分析时，程序从本轮引用的比较结果生成摘要和每位会员的 `rationale`，模型继续生成 `suggestion`。建议的业务价值和消费下降原因仍需人工判断。新增字段不改变金额口径、能力矩阵和 W01 提交契约。
